# Загрузчик видео для Android

Одно окно: вставляете ссылку, нажимаете «Найти», выбираете качество, нажимаете «Скачать».
Работает на yt-dlp и ffmpeg (библиотека youtubedl-android), качает в фоне с уведомлением
и сохраняет файлы в `Фильмы/VideoDownloader` (аудио в `Музыка/VideoDownloader`).

Требуется Android 10 и новее, 64-битный телефон (arm64).

## Как собрать APK на GitHub

1. Создайте на GitHub новый репозиторий (можно приватный).
2. Загрузите в него **все файлы из этого архива с сохранением папок**, включая скрытую папку `.github`.
   Проще всего через git:
   ```
   git init
   git add .
   git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
3. Откройте вкладку **Actions**. Сборка стартует сама после загрузки (или нажмите
   **Build APK → Run workflow**). Первая сборка занимает 5–10 минут.
4. Когда сборка станет зелёной, откройте её и внизу в разделе **Artifacts** скачайте
   `video-downloader-apk`. Внутри zip будет `app-debug.apk`.
5. Перенесите APK на телефон и установите (разрешите установку из неизвестных источников).
   Play Protect может предупредить о неизвестном приложении, это нормально для собственной сборки.

## Что умеет

- Принимает ссылку через пункт «Поделиться» в браузере и других приложениях.
- Показывает доступные разрешения с примерным размером, плюс «Лучшее доступное» и «Только аудио (mp3)».
- Во время загрузки кнопка «Скачать» превращается в «Отмена»; отмена есть и в уведомлении.
- При каждом запуске приложения обновляет yt-dlp (внизу экрана видно версию и результат).

## Если что-то не работает

- **Сайт перестал качаться.** Увеличьте версию библиотеки в `app/build.gradle.kts`
  (строка `val youtubedlAndroid = "..."`, актуальную версию смотрите на
  https://github.com/yausername/youtubedl-android) и пересоберите.
- **Нужны 32-битные телефоны.** В `app/build.gradle.kts` добавьте
  `abiFilters.add("armeabi-v7a")`. APK станет примерно вдвое больше.
- **Ошибка сборки в Actions.** Откройте красную сборку, скопируйте последние строки лога
  и пришлите их, чтобы поправить.
